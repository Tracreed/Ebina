# Future Features Roadmap

This document outlines the planned features for the Ebina web dashboard.

## Moderation & Management

*   **Automod Configuration:** A panel to set up rules for automatically deleting messages containing spam, specific keywords, or excessive mentions.
*   **Logging Configuration:** Allow server admins to choose which events (e.g., members joining/leaving, message deletions) are logged to a specific channel.
*   **Welcome Messages:** A feature to configure custom welcome messages or banners for new members.

## Engagement & Utility

*   **Reaction Roles:** An interface for setting up roles that are automatically assigned when a user reacts to a specific message.
*   **Custom Commands:** A section to create or manage simple, custom server commands.

## Analytics

*   **Activity Dashboard:** Visual charts showing server activity over time (e.g., messages per day, new members per week).
*   **Top User/Channel Stats:** Leaderboards showing the most active users and most popular channels.
